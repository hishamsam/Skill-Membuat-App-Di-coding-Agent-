# Prompt Mod Auto

Salin, ganti bahagian dalam `[...]`, hantar sebagai mesej pertama.

## Bahasa Melayu

```text
Bina [idea aplikasi] dalam mod auto penuh.

Keperluan:
- Guna aliran kerja repo ini: Fasa 1 PRD -> Fasa 2 FigCraft -> Fasa 3 kod
  responsif -> Fasa 4 ujian tempatan.
- Jangan tanya soalan temubual. Pilih stack sendiri dan rekod andaian
  dalam PRD Bab 5.
- Rujukan imej: [projek/<slug>/refs/ atau tiada].
- Kod mesti responsif 360-1920px, tiada butang mati, tiada dark mode.
- Jalankan qa-check.sh dan test-local.sh --check; jangan lapor siap tanpa
  output sebenar.
- Berhenti sebelum deploy, pembayaran, DNS, atau akaun production.

Laporkan pada akhir: PRD, design, fail kod, keputusan ujian, blocker.
```

## English

```text
Build [app idea] in full auto mode.

Requirements:
- Follow this repo's workflow: Phase 1 PRD -> Phase 2 FigCraft -> Phase 3
  responsive code -> Phase 4 local test.
- Do not ask interview questions. Choose the stack yourself and record every
  assumption in PRD Chapter 5.
- Reference images: [projek/<slug>/refs/ or none].
- Code must be responsive 360-1920px, with no dead buttons and no dark mode.
- Run qa-check.sh and test-local.sh --check; do not report success without
  real output.
- Stop before deploy, payments, DNS changes, or production accounts.

Report at the end: PRD, design, code files, test results, blockers.
```
